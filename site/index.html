01 / THE IDEAMore signal. Less friction.

Good skills deserve
a better view.

Agent skills are easy to collect and harder to keep track of. SkillView puts discovery, context, and maintenance together in one keyboard-first workspace.

Use the full-screen interface when you want to explore. Reach for the CLI when you want to automate.

⌕01 — FIND

Explore with context

Search public skills, narrow results by owner or agent, and inspect a skill’s content before making a choice.

◇02 — ACT

Install with intent

Choose where a skill goes and which agents use it. Review the plan before SkillView hands it to gh skill.

↺03 — MAINTAIN

Keep things tidy

See what’s installed, check for updates, review cleanup candidates, and inspect your environment with Doctor.

The TUI gives you room to explore and review. The CLI gives scripts the same essential workflows with JSON output and useful exit codes.

Explore CLI commands ↗
● SKILLVIEW / CLI
# Check your setup
$ skillview doctor --json

# Find and inspect skills
$ skillview search terraform

# Inventory and maintenance
$ skillview list --json
$ skillview update --dry-run
