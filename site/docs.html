Install SkillView

You need GitHub CLI version 2.102.0 or newer. For search and installation, authenticate with gh auth login.

Recommended: GitHub CLI extension

gh extension install harder/gh-skillview
gh skillview

Update it later with gh extension upgrade harder/gh-skillview.

Homebrew (macOS Apple Silicon and Linux x64)

brew install harder/tap/skillview
skillview

This installs the standalone app and its gh dependency. Update with brew upgrade harder/tap/skillview. The formula is maintained in the SkillView Homebrew tap.

Standalone app

Download a self-contained binary from the latest release and put it on your PATH. No separate .NET runtime is needed.

Your first five minutes

  1. Launch the app with gh skillview or skillview.
  2. Search for a topic or skill and browse the Discover results.
  3. Select a result to read its SKILL.md before installing.
  4. Press i to review a standard install, or I for more options.
  5. Open Installed with 2 to see your local skills.

Find your way around

SkillView has three main tabs: Discover for finding and previewing skills, Installed for your local inventory, and Issues for captured findings and supported repairs. Doctor and cleanup findings are available on demand.

Inspect an exact physical copy and its recorded consumers before choosing an action. Update availability is checked explicitly; findings and suggestions never apply changes by themselves. Saved updates review source changes and permission to retain the original separately, with a fresh review for Undo.

Use F5 for Locations and F4 for retained-operation History. Local browsing does not require a remote authentication check.

This guide follows the development version and may be ahead of your installed release. Check skillview --version and press ? or F1 for the current screen’s shortcuts.

Find skills wherever you keep them

Use Discover for public repository search and read-only previews. Use Installed for physical copies already on disk: user and project agent folders, universal/shared placements, and observed managed or plugin skills. Read-only inventory does not require remote authentication.

Review a supported fix

Choose an exact physical copy and inspect its consumers first. Findings, comparisons and suggestions do not approve writes. Source-changing plans freeze a candidate for review; source acknowledgement and permission to retain the original are separate. A changed target or uncertain ownership can refuse the action.

After an attempted write, refresh inventory before another review. Filesystem success, inventory verification and running-agent reload are separate facts.

Undo, recover and inspect retained data

Use fresh inspection before Undo or recovery; the original apply fingerprint is not current restoration approval. F4 History lists saved replacements and offers admitted inspection, abandonment of an unapplied review or explicit Discard Undo data. Discard is permanent; retained data is never purged automatically.

Moved-aside copies have a separate quarantine-history and undo --id workflow; F4 does not list quarantine. replacement-history gives saved-replacement hints, while history verifies retained backup journals and payload blobs. Interrupted or unknown operations remain protected for purpose-specific inspect/recover/undo commands.

Keep the same HOME/state, launch directory, workspace/profile/scan-root flags and saved IDs through review and recovery. Never delete journals to clear an error. Read the saved-update guide, recorded restoration, Move aside and Undo, and complete action matrix.

Work from the command line

Add a subcommand to run SkillView without the full-screen interface. Use gh skillview in place of skillview when installed as an extension.

skillview doctor
skillview search terraform
skillview preview OWNER/REPO SKILL
skillview install OWNER/REPO SKILL
skillview list --json
skillview queue --json
skillview --scan-root /path/to/skills check --path /path/to/skills/demo --json
skillview update --all --dry-run
skillview cleanup

Commands that support --json can feed scripts and AI agents. Run skillview --help for flags and options. Put global flags such as --scan-root before the subcommand:

skillview --scan-root /path/to/skills list --json

When something feels off

Run skillview doctor to inspect your GitHub CLI path, version, authentication, detected agent homes, and log location. In the TUI, press d.

For a bug report, include skillview --version, your OS and terminal, the command or flow you used, and whether gh auth status succeeds. Run with --debug if you need a more detailed log.
