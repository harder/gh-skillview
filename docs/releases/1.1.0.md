# SkillView 1.1.0

SkillView 1.1 brings discovery, diagnosis and reviewed maintenance together in
three primary tabs: **Discover**, **Installed** and **Issues**. The standalone
`skillview` app and `gh skillview` extension offer the same core workflows.

## What's new since 1.0.1

- **Find and inspect the right copy.** Search and preview skills, filter installed
  copies by agent, location, owner or issue, compare independent copies, and
  inspect physical payloads and their recorded consumers. Locations adds
  workspaces, scan roots and profiles without launching AI clients.
- **Diagnose with context.** Package checks report metadata and Markdown resource
  problems. Coverage and ownership findings keep unavailable locations, conflicting
  evidence and unknown state visible. Contextual help and the
  [find, diagnose and fix guide](../find-diagnose-fix.md) explain the next review.
- **Review updates before applying them.** Prepare a saved candidate, inspect its
  source, then approve retention and apply that exact saved operation. Guided
  review handles eligible items one at a time. History supports fresh Undo,
  interrupted-operation recovery and explicit retirement of retained state.
- **Use the repair route that matches the problem.** Purpose-specific workflows
  cover recorded restoration, local reimport, local source switching, unpin,
  removal and Move aside. Each retains its own identity, ownership and approval
  checks; a scan or recommendation does not authorize a write.
- **Updated runtime and documentation.** Native builds use .NET 10.0.14 and the
  pinned Terminal.Gui/Editor package pair. The website, screenshots, animations
  and command guides now cover the 1.1 feature set, including mobile browsing.
  Removal review keeps long paths and ownership details in a scrollable pane
  above the confirmation controls, including at 80×24.

See the [supported actions matrix](../supported-actions.md) and
[usage guide](../usage.md) for command and selection details. Experimental generic
plan/apply wrappers and authoring/evaluation tools developed after 1.0.1 were
retired before this release. Supported historical saved operations retain their
compatibility and recovery paths.

## Upgrade

Install **GitHub CLI 2.102.0 or newer** first. Authentication remains delegated
to `gh`; use `gh auth login` when remote search or installation requires it.

For an existing extension installation:

```bash
gh extension upgrade harder/gh-skillview
gh skillview --version
```

For an existing Homebrew installation on Apple Silicon macOS or x86_64 Linux:

```bash
brew update
brew upgrade harder/tap/skillview
skillview --version
```

The Homebrew tap updates separately after validating the published release on
macOS and Linux. Until that update arrives, use the release download or extension.
Standalone users can replace their executable with the matching release asset
after checking its `SHA256SUMS` file. No .NET installation is required for the
Native AOT binaries. Supported targets are Windows x64, Windows ARM64, Linux x64
and macOS ARM64; Linux ARM64 and Intel macOS binaries are not supplied.

## Review and recovery boundaries

Keep retained originals and saved operation state until you have finished any
needed Undo or recovery. Reinspect a saved operation before approving a mutation;
old inventory output or an earlier approval is not fresh authority. Filesystem
or security-metadata limitations can still refuse a replacement safely. See
[saved updates](../saved-updates.md) and
[recorded restoration](../recorded-restoration.md).

The refreshed media uses a disposable sample inventory captured before the
1.1.0 version bump. Its [source and capture provenance](../media.md) is preserved.
Screenshots illustrate review paths; they do not establish live remote execution
or human acceptance on every supported terminal.
