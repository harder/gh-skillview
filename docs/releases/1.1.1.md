# SkillView 1.1.1

SkillView 1.1.1 restores simpler terminal browsing after the 1.1.0 UX regression
and updates the supported .NET 10 dependencies.

## Clearer everyday browsing

- Discover, Installed and Issues return to a simpler layout, with persistent
  screen headings, distinct table headers and an unfilled gold heading palette.
- Routine inspection stays compact. Detailed repair work opens in contextual
  dialogs and review flows.
- Browse menus and keyboard navigation are corrected. Active filters and startup
  errors remain visible in narrow terminals, copy labels distinguish similarly
  named locations, and long consumer lists stay bounded.
- Skill previews preserve literal tildes in paths and descriptions. Screenshots,
  walkthroughs and website guidance reflect the refreshed interface.

## Dependency and GitHub CLI compatibility

- Native builds use .NET 10.0.15 with SDK 10.0.404. The test platform and filesystem
  abstraction dependencies receive coordinated updates.
- GitHub CLI 2.105.0 is reviewed and tested alongside the supported minimum,
  2.102.0. There are no new `gh skill` commands or agent-catalog changes in the
  reviewed versions that require a different SkillView workflow.

## Upgrade

For an existing GitHub CLI extension installation:

```bash
gh extension upgrade harder/gh-skillview
gh skillview --version
```

For Homebrew on Apple Silicon macOS or x86_64 Linux:

```bash
brew update
brew upgrade harder/tap/skillview
skillview --version
```

The Homebrew tap updates separately after validating the published binaries on
macOS and Linux. Standalone users can replace their executable with the matching
release asset after checking its `SHA256SUMS` file. No .NET installation is
required. Supported binaries cover Windows x64, Windows ARM64, Linux x64 and
macOS ARM64.

Keep retained originals and saved operation state for any needed Undo or
recovery. Existing saved-operation review and approval requirements continue to
apply.
