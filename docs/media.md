# Current terminal screenshots

The current PNGs and GIFs in `assets/screenshots/` and `assets/animations/` were
captured from the pre-release 1.1 app at `c2dbc5279755d1e71219155a7d36f94684ae8f4c`.
They show actual Terminal.Gui output from a 120-column × 36-row PTY with a
credential-free, disposable sample inventory. The source revision predates the 1.1.0 version bump. These captures document
the 1.1 feature set, rather than a new run of the tagged release binary.

The fixture contains independent same-name copies, an intentional project
variation, a shared payload, a broken link, an empty directory, malformed metadata,
conflicting authored/lock evidence, an unmatched registry record, a managed
read-only copy and a missing Markdown resource. Incomplete coverage remains
visible. These are sample files and claims, not the maintainer's installed skills.
Discover uses a narrow sample-response adapter for the submitted `terraform`
query and preview. Doctor truthfully shows no remote login in this context.
No credentials are copied, no AI client or skill code runs, and no install,
replacement, removal or Move aside is performed. Removal/install screenshots
show review dialogs only; animations end with review/cancellation or inspection.

PNG rendering uses the captured VT cell grid and ANSI colors with DejaVu Sans
Mono. It does not reconstruct the terminal cursor or every terminal text style.
Terminal text is not rewritten for the images. GIFs are ordered settled captures
with edited holds, rather than continuous recordings or latency evidence.
The [capture manifest](../assets/screenshots/capture-provenance.txt) records
source/binary hashes, frame offsets, text/media hashes and fixture preservation.
Historical text receipts in the screenshots directory remain historical evidence.

To make a new capture, build the pinned checkout, follow the isolated child
HOME/state/CWD and refusing-adapter setup in [PTY testing](../agent_docs/tui-pty-testing.md),
and bind the built host/Core assemblies to the source revision. Set the actual
PTY size, answer terminal startup probes and wait for complete settled controls.
Navigate through Discover, Installed, Issues, Locations, an exact package check,
a chosen-reference comparison, Doctor and Help. Review dialogs must be cancelled.
Retain raw ANSI, submitted keys, rendered cells and before/after fixture identities.
Do not reuse a screenshot from a different source revision without saying so.

Keep media masters under `assets/`; `python3 site/build.py` copies the selected
PNGs to the ignored `dist/skillview-site/media/` folder. Update image dimensions,
alt text and fixture captions when changing captures. Verify the website at both
desktop and phone widths and check local links after the build.
